# MC Translator

Инструмент для автоматического перевода модпаков Minecraft — интерфейсы модов, квесты (FTB Quests, KubeJS), книги-гайды (Patchouli, GuideME) и конфиги — на другой язык, без поломки игровых кодов форматирования и без вреда для оригинальных `.jar`-файлов модов.

Настольное приложение (GUI на pywebview) с полноценным headless CLI-режимом для автоматизации.

## Зачем это нужно

Обычный машинный перевод "в лоб" ломает модпаки: переводчик может исковеркать переменную `%s`, тег `<item:minecraft:dirt>`, markdown-ссылку `[text](url)` или цветовой код `&6` — и мод либо крашится, либо теряет часть интерфейса (частая история с *Applied Energistics 2* и гайдами *Patchouli*).

MC Translator перед отправкой текста в переводчик **маскирует** все подобные фрагменты плейсхолдерами вида `[#0#]`, а после перевода строго восстанавливает их на исходные места. Если переводчик всё же испортил плейсхолдер (потерял, переставил, слепил несколько соседних кодов в один нечитаемый ком) — перевод этой строки просто отбрасывается и остаётся английский оригинал, вместо того чтобы отправить в мод повреждённый текст.

## Что умеет

- **Несколько независимых движков перевода** — от бесплатного Google Translate до локальных и облачных нейросетей (список ниже).
- **Кэш переводов** с самовосстановлением: при каждом запуске программа проходится по уже переведённым строкам и чинит типичные огрехи (пробел внутри `% s` → `%s`, разъехавшиеся скобки и т.п.).
- **Свой словарь терминов** (`dictionary.json`) — если движок упорно переводит "Raw Copper" как "Сыромятная медь", один раз добавляете правило "Сыромятная медь → Сырая медь", и оно применяется по всему кэшу и ко всем новым переводам.
- **Экран проверки переводов** — таблица «оригинал / перевод / в каких модах встречается» с возможностью тут же поправить строку вручную; правка сразу уходит в кэш.
- **Инкрементальный перевод** ("Доперевод"): режимы `append` (дополнить, не трогая готовое), `skip` (пропустить почти готовые файлы) и `force` (перевести с нуля).
- **Вывод в Resource Pack + Data Pack** (по умолчанию, ничего в самой сборке не меняется) либо прямая правка файлов на месте.
- **Широкий охват форматов**: языковые файлы модов (`lang`/generic JSON), `.lang`, NBT (`.nbt`/`.dat`), YAML/TOML-конфиги, обычный текст (`.txt`/`.md`), CFG, XML, BAT, `.mcfunction`, а также содержимое архивов (`.zip`, `.mcpack`, `.mcaddon`, `.litemod`).
- **Квесты и книги отдельно от интерфейса**: FTB Quests (включая раскладку под мод Lang Splitter) и KubeJS-квесты, книги Patchouli/GuideME — со своим "контекстным" режимом перевода, учитывающим лор сборки.
- Автоопределение версии Minecraft по файлам лаунчера (Prism Launcher/MultiMC, CurseForge App, ATLauncher, Technic, ванильный лаунчер, GDLauncher).

## Поддерживаемые языки

Перевод с английского на: русский, украинский, испанский, немецкий, французский, упрощённый китайский, японский, корейский, португальский, итальянский, польский, а также английский (UK) как отдельный вариант.

## Движки перевода

| Движок | Когда использовать |
|---|---|
| **Google Translate** | Быстро и бесплатно, без ключей. Есть построчный (точнее) и пакетный (быстрее) режимы. |
| **DeepL API** | Более качественный перевод прозы, нужен свой API-ключ deepl.com. |
| **ИИ — Локально (KoboldCPP)** | Полный контроль, ничего не уходит в интернет. Можно настроить одной кнопкой: программа сама определит видеокарту, скачает подходящую по размеру модель и движок KoboldCPP. |
| **ИИ — OpenRouter (облако)** | Доступ ко множеству нейросетей по одному ключу. Есть авто-перебор бесплатных моделей: при исчерпании лимита одной модели — переключение на следующую, а когда закончатся все — ожидание сброса дневного лимита без остановки программы. |
| **ИИ — Другой ИИ (свой API)** | Любой OpenAI-совместимый API: NVIDIA NIM (много бесплатных моделей), OpenAI, Google Gemini, Groq, DeepSeek, Mistral, локальный Ollama/LM Studio/vLLM и т.д. Есть готовые пресеты для быстрой настройки URL. |
| **ИИ — Claude (Anthropic)** | Отдельная интеграция под протокол Anthropic (не OpenAI-совместимый). |

Для ИИ-движков есть два режима перевода: **«Безопасный»** (пакеты по 20 строк) и **«Контекст + лор»** (пакеты по 40 строк с подсказкой о теме/лоре сборки — для более связного перевода книг и квестов).

Настройки всех движков — в разделе «⚙ Настройки» приложения, ключи и параметры хранятся в `settings.ini` рядом с программой.

## Установка и запуск

**Готовая сборка для Windows** (без установки Python): скачайте `MC_Translator_*_win64.zip` со страницы [релизов](https://github.com/KiLlEr135/mc-translator/releases/latest), распакуйте и запустите `MC_Translator.exe`.

Запуск из исходников требует Python 3.10+.

```
git clone <URL этого репозитория>
cd Progect-Minecraft-Translate
pip install -r requirements.txt
python -m mc_translator
```

Либо просто запустить `start.bat` — он сам поставит зависимости и откроет приложение.

Без аргументов запускается GUI. С аргументами — headless CLI-режим:

```
python -m mc_translator --mc-dir "C:\...\minecraft" --lang Русский --engine ai --mode append
```

Основные флаги: `--mc-dir`, `--lang`, `--mc-version`, `--engine {google,deepl,ai}`, `--mode {append,skip,force}`, `--output {resourcepack,inplace}`, `--pack-name`, `--analyze-only`, `--no-mods`, `--no-books`, `--no-quests`. Полный список — `python -m mc_translator --help`.

### Сборка .exe

```
build.bat
```

Собирает `dist\MC_Translator.exe` через PyInstaller (конфигурация — в `MC_Translator.spec`). Рядом с готовым `.exe` при необходимости положить `settings.ini`, `dictionary.json`, `cache.json`.
