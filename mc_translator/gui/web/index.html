⚙ Настройки MC Translator

Определит вашу видеокарту, скачает подходящую по размеру модель и движок KoboldCPP и настроит поля ниже сама.

Ключ: openrouter.ai/keys

🔁 Авто-перебор бесплатных моделей включается кнопкой в панели «Нейросеть» слева. При исчерпании лимита одной бесплатной модели программа сама переключится на следующую, а когда закончатся все — подождёт сброса лимитов и продолжит.

Любой ИИ с OpenAI-совместимым API (chat/completions): NVIDIA NIM (много бесплатных моделей), OpenAI, Google Gemini, xAI Grok, Groq, DeepSeek, Mistral, локальный Ollama/LM Studio и т.д.

При лимите запросов (429) программа сама подождёт сброса и продолжит с той же моделью — без переключения (для многих API, включая NVIDIA NIM, лимит общий на весь ключ, а не на отдельную модель, так что смена модели всё равно не помогает).

Claude — отдельный протокол (не OpenAI-совместимый), поэтому своя вкладка. Ключ: console.anthropic.com

Какие типы файлов переводить (в дополнение к переключателям «Что переводим?» в сайдбаре). По умолчанию — все включены.
